# NutriGuide AI

NutriGuide AI is an AI-powered nutrition guidance web application built with **Python, Streamlit, and Google Gemini AI**.

## Features

* AI-based nutrition assessment
* Safety check
* Personalised general nutrition guidance
* Meal ideas
* Results dashboard
* Downloadable PDF report
* API error and quota handling

## Technologies

* Python
* Streamlit
* Google Gemini AI
* ReportLab
* python-dotenv

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

Add your Gemini API key as:

```text
GEMINI_API_KEY=your_api_key
```

> **Note:** NutriGuide AI provides general educational nutrition guidance and is not a replacement for professional medical or nutrition advice.
